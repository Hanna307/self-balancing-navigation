# Self-Balancing Robot with Navigation

## Graduation Project

A two-wheeled self-balancing robot combined with navigation.

## Main Objectives

- Develop the mathematical model of the self-balancing robot.
- Simulate the robot dynamics using Python.
- Implement sensor fusion using Complementary Filter and Kalman Filter.
- Design PID-based balance control.
- Develop velocity and heading control.
- Implement odometry and waypoint navigation.
- Port the control algorithms to STM32.
- Integrate and test the complete system on the real robot.

## Development Approach

Mathematical Model
→ Python Simulation
→ Filter
→ PID Control
→ Navigation
→ STM32 Firmware
→ Real Robot
